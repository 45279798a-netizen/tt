# Project Resonance：緣起 — 本機私服（3D 割草 × 免洗版魔物獵人）

3D 上帝視角自動割草 ARPG。Three.js 3D 戰鬥 + React / Tailwind CSS 介面 + Node.js (Express) 後端，在你自己的電腦上跑。

## 🚀 最快開始（Windows）

1. 先安裝 [Node.js](https://nodejs.org)（選 LTS 版本，一路下一步）
2. 雙擊 **`啟動私服.bat`** → 第一次會自動安裝套件，跑完就開好伺服器了
   - 電腦玩：瀏覽器開 `http://localhost:3000`
   - 同 Wi-Fi 的手機：開視窗裡顯示的「區域網路」網址
3. 要給外面的朋友玩、或要安裝到手機：再雙擊 **`開啟外網連線.bat`**，把它顯示的 `https://….trycloudflare.com` 網址傳出去

| 檔案 | 用途 |
|---|---|
| `啟動私服.bat` | 開伺服器（視窗要一直開著，Ctrl+C 關閉並存檔） |
| `開啟外網連線.bat` | 產生 https 網址給朋友 / 手機安裝用（第一次會自動裝 cloudflared） |
| `開啟固定網址.bat` | ⭐ 推薦：用 Tailscale Funnel 開一個**永遠不變**的 https 網址（免費） |
| `關閉固定網址.bat` | 關掉固定網址的對外連線 |
| `開發模式.bat` | 改程式時用，存檔自動更新畫面（開 `http://localhost:5173`） |

### 🔗 固定網址（推薦）

`開啟外網連線.bat` 每次網址都會變；`開啟固定網址.bat` 用 [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel)，網址長這樣、永遠不變：
`https://你的電腦名稱.某某.ts.net`

1. 雙擊 `開啟固定網址.bat`，第一次會自動安裝 Tailscale
2. 點右下角工作列的 Tailscale 圖示，用 Google / Microsoft 帳號登入（免費）
3. 先開 `啟動私服.bat`，再雙擊一次 `開啟固定網址.bat`
4. 第一次會跳出一個 `https://login.tailscale.com/...` 網址，打開按允許
5. 視窗最後顯示的 `https://….ts.net` 就是固定網址，傳給朋友一次就好

朋友**不用**裝 Tailscale，直接開網址就能玩、能安裝成 App。設定會一直保留，之後開機只要開 `啟動私服.bat`。

```bash
cd project-resonance

```

## 開發模式（改程式會自動重新整理）

```bash
npm run dev
```

- 後端 API：http://localhost:3000
- 前端畫面：http://localhost:5173 ← 開這個
- 手機測試：手機和電腦連同一個 Wi-Fi，打開 Vite 印出的 `Network: http://192.168.x.x:5173`

## 📲 安裝到手機、橫向全螢幕玩

遊戲是**橫向**的，直拿手機會提示轉向。安裝成 App 後從主畫面打開會直接**全螢幕 + 鎖橫向**，沒有網址列。

⚠️ 手機安裝（PWA）規定一定要 **https**，`http://192.168.x.x` 這種內網網址只能在瀏覽器裡玩、不能安裝。做法：

1. 電腦執行 `npm start`
2. 另開一個視窗，二選一：
   - `cloudflared tunnel --url http://127.0.0.1:3000`（免註冊，會給你一個 `https://xxxx.trycloudflare.com`）
   - `ngrok http 3000`（需註冊，免費版第一次開會有一頁警告，按 Visit Site 即可）
3. 手機打開那個 https 網址：
   - **Android（Chrome）**：登入畫面會出現「📲 安裝到手機主畫面」按鈕，或選單 →「安裝應用程式」
   - **iPhone（Safari）**：分享 →「加入主畫面」。iOS 不允許網頁鎖定方向，請把手機的方向鎖定關掉再橫拿

在瀏覽器裡玩（沒安裝）時，右上角有「全螢幕」按鈕，Android 會順便鎖成橫向。

> 注意：cloudflared / ngrok 免費版每次重開網址都會變，網址變了朋友要重新安裝一次。想固定網址可以用 ngrok 的免費固定網域或 Cloudflare 帳號建立正式 tunnel。

## 私服模式（給朋友玩）

```bash
npm start
```

會先打包 React，再由 Node.js 在 **3000 埠** 同時提供畫面與 API。啟動時終端機會印出區域網路網址。

- 同 Wi-Fi 的朋友：直接開 `http://你的內網IP:3000`
- 外面的朋友 / 要安裝成 App：用上面的 cloudflared 或 ngrok，把 https 網址傳給朋友
- Windows 第一次啟動若跳出防火牆詢問，請允許「私人網路」

存檔位置：`server/data/players.json`（關伺服器時按 Ctrl+C 會強制存檔）。想重開新世界就刪掉這個檔案。

## 設計重點

- **要真的在打才有收益**：已移除離線掛機。收益來自你畫面上真的打倒的怪，每 2 秒回報一次；在村莊、離線、切到別的 App（畫面隱藏）都不會有收益。
- **防作弊**：伺服器依你的戰力算出「這段時間最多可能打倒幾隻」（理論擊殺速度 × 1.6 倍寬限），超過的直接砍掉；回報間隔最多算 8 秒，斷線再連回來不會補發。
- **數值曲線**：每張地圖怪物血量 ×30、裝備數值 ×30，素材需求每區 ×2.2（`items.js` 的 `TIER_MATS`）。
- **前往下一區的戰力門檻**：自動用「上一區整套、每件強化 +N」算出來（`formulas.js` 的 `REQ_BUILD`），改裝備數值門檻會自動跟著變。

## ⚒ 裝備：隨機數值、強化、分解

- **每次鍛造都是一件新裝備**，放進背包（上限 120 格），數值都不一樣：
  - 主屬性浮動 85% ~ 115%
  - 品質：普通 50%（1 條附加）/ 精良 30%（2 條）/ 稀有 15%（3 條）/ 傳說 5%（4 條，主屬性 +10%）
  - 附加屬性：攻擊% / 生命% / 防禦% / 暴擊率 / 暴擊傷害 / 金幣獲取 / 經驗獲取 / 素材掉落（依部位不同）
- **強化**：綁在那一件裝備上，換裝**不繼承**；每級主屬性 +6%，花金幣 + 💠鍛造精華
- **分解**（背包）：得到 💠鍛造精華 + 退回 25% 普通素材；強化過的裝備分解會退一半精華
  - 穿著中、🔒上鎖、新手木劍不能分解；有「一鍵分解 普通 / 普通＋精良」
- **💠鍛造精華的用途**：強化、洗鍊（重骰附加屬性，品質和條數不變）
- 刷寶循環：狂鍛造 → 留好的 → 爛的分解成精華 → 精華拿去強化 / 洗鍊
- 解鎖下一區看「鍛造圖鑑」：做過就算，分解掉也不會被鎖回去
- 舊存檔會自動轉換：原本擁有的裝備變成普通品質，身上部位的強化等級轉到那件裝備上

- **首領突襲**：所有成員都有保底獎勵＋1 顆寵物蛋，傷害比例另外加成（拿掉原本 2% 傷害門檻）

## ✨ 技能特效（three.quarks）

所有技能、普攻、狂熱的特效都是 three.quarks 粒子系統（`client/src/game3d/quarksFx.js`），每招由多層組成：

- 各招的組合在 `client/src/game3d/skills.js`，傷害倍率跟特效分開，改特效不影響平衡

## ⚔ PvP 決鬥

- 同地圖的朋友名字會出現在畫面上方（`小華 ⚔`），點下去選模式發起決鬥：
  - **公平對決**：雙方血量、攻擊力一樣，比走位和出招時機
  - **戰力對決**：用真實戰力，裝備越好越強
- 對方接受後兩人傳送到紅色圈圈的競技場，倒數 3 秒開打，上方顯示雙方血條和剩餘時間（90 秒）
- 傷害、射程、冷卻全部由伺服器判定（`server/game/realtime.js`），打不到的距離不算、按太快不算
- 血量歸零、投降、斷線或時間到（血量比例高的贏）分出勝負，戰績顯示在「首領」頁排行榜

## 👥 多人同地圖

- 同一張地圖的玩家會即時看到彼此（位置、裝備外觀、武器、名字和等級）
- 朋友的普攻與技能特效你也看得到，而且會打到你畫面上的怪，像一起組隊狩獵
- 換到不同地圖就看不到對方；畫面中央會顯示「👥 同地圖 N 人」
- 技術上用 WebSocket（`server/game/realtime.js`），每 0.1 秒同步一次；如果 WebSocket 被通道 / 防毒 / 瀏覽器擋掉，會自動改用「相容模式」（一般網頁請求輪詢），一樣看得到彼此
- 伺服器視窗會印出 `[連線] 阿明 進入第 3 區（WebSocket）`，可以用來確認朋友有沒有連上
- **每個人要用不同的名字登入**，同名字 = 同一個角色，會互相把對方擠下線

## 3D 戰鬥操作

- **自動**：角色自動找最近的怪、邊走邊 AoE 普攻、技能冷卻好就自己放（決鬥時會自動追對手）
- **手動**：完全不會自己走、不會自己打，全靠左下搖桿走位、右下按鈕出招（會記住你的選擇）
- 金幣 / 經驗 / 素材看你實際打倒幾隻，自動、手動都一樣算
- 左下搖桿：拖曳立刻接管走位，自動模式下放開 1.2 秒後自動接回
- 右下技能盤：大按鈕是強力普攻（可狂點），周圍 4 顆是你在「角色 → 技能」選的招式
- 菁英營地（小地圖上的骷髏）和一般營地偶爾會出大型菁英怪（血量 ×10，收益算 10 隻）
- 切到其他分頁會暫停 3D 渲染以省電

## 說明

- 3D 角色和怪物目前是程式生成的低多邊形模型，不需要任何美術素材。之後想換成真正有骨架動畫的模型，可以把 `.glb` 檔放進 `client/public/models/`，在 `BattleScene.js` 用 `GLTFLoader` 載入替換（推薦免費素材：Quaternius、Kantan、Kenney）。
- 收益以畫面上的擊殺為準，但伺服器會用秒傷算出合理上限（防作弊）。
